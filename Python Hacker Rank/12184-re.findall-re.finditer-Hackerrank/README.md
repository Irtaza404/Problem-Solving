<p>The expression <em>re.findall()</em> returns all the non-overlapping matches of patterns in a string as a list of strings. <br>
<sub><strong>Code</strong></sub></p>

<pre><code>&gt;&gt;&gt; import re
&gt;&gt;&gt; re.findall(r'\w','http://www.hackerrank.com/')
['h', 't', 't', 'p', 'w', 'w', 'w', 'h', 'a', 'c', 'k', 'e', 'r', 'r', 'a', 'n', 'k', 'c', 'o', 'm']
</code></pre>
