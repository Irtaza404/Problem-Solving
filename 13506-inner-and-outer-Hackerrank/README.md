<p>The <em>inner</em> tool returns the <a href="https://en.wikipedia.org/wiki/Inner_product_space">inner product</a> of two arrays.</p>

<pre><code>import numpy

A = numpy.array([0, 1])
B = numpy.array([3, 4])

print numpy.inner(A, B)     #Output : 4
</code></pre>

<p><a href="http://docs.scipy.org/doc/numpy/reference/generated/numpy.outer.html"><strong>outer</strong></a>    </p>

<p>The <em>outer</em> tool returns the <a href="https://en.wikipedia.org/wiki/Outer_product">outer product</a> of two arrays.</p>

<pre><code>import numpy

A = numpy.array([0, 1])
B = numpy.array([3, 4])

print numpy.outer(A, B)     #Output : [[0 0]
                            #          [3 4]]
</code></pre>
